Changes from REL.PRU-ICSS-ETHERNET-SWITCH_02.02.15.00 to REL.PRU-ICSS-ETHERNET-SWITCH_02.02.15.02

- Updated mask to get receive frame error bits status (from 0x0000 to 0x3180)
- Changed TX PRU wait on TX L1 FIFO level from 6B to 8B, for 100M speed.
- Moved some of the R30 register persistent bits from lower host configurable bits to upper firmware managed bits.
